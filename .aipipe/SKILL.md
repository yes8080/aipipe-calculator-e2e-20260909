# aipipe

读取同目录 [AGENTS.md](AGENTS.md)，确认用户当前目标、仓库已有状态及已获得的授权，然后只加载相应的独立 Skill。多个能力可以组合，但不把它们串成必须经过的固定流程。

先区分传统项目与已接入 aipipe 的项目：传统项目正式接入先初始化配置，不生成开发方案；已接入项目可直接接手 Issue 或验收 PR。只补 App、只设计文档或只发布切片时分别选择该能力。`docs/` 是可选需求入口，不是所有操作的前置条件。

原生发现与手工调用方式见 [工具接入](references/tools.md)。
