# 清算 · 网页计算器

一个零依赖网页计算器，也是 aipipe 从项目初始化到 GitHub 独立验收和合并的测试项目。

## 本地运行

需要 Node.js 20+、npm；静态服务示例需要 Python 3。

```sh
npm test
npm run build
npm start
```

打开 http://localhost:4173 。也可将 `dist/` 部署到任何静态服务器。没有第三方依赖，不需要安装依赖。

## 使用

支持四则运算、运算符优先级、小数、负数（如 `2*-3`），以及数字键和 `+ - * / .` 键盘输入。Enter 或 `=` 计算，Backspace 退格，Escape / AC 清空。结果后输入数字开始新算式，输入运算符继续计算；重复等号保持当前结果。Tab 可遍历按键，空格激活聚焦按键；Enter 始终计算。

除零和不完整算式显示中文错误；输入新数字或清空可恢复。小数结果保留 12 位有效数字，消除 `0.1 + 0.2` 的浮点尾差；支持结果绝对值小于 `10^15`、非零结果绝对值不低于 `10^-12`，超出范围显示错误。最多输入 120 个字符。不支持括号、指数输入或百分比。

## 实现与验收

- `src/calculator.mjs`：无 `eval` 的优先级解析器与独立输入状态机。
- `src/app.mjs`：按钮、键盘与可访问输出。
- `tests/calculator.test.mjs`：Node 内置测试，覆盖计算、输入状态和错误恢复。
- `scripts/build.mjs`：语法与资源检查，复制静态产物到 `dist/`。

UI 支持 320px 屏幕和可见键盘焦点，输出使用 live region。GitHub CI 执行与本地相同的测试、构建命令，独立 reviewer 绑定 PR 当前 SHA 验收。
