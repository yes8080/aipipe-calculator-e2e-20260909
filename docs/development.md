# 网页计算器开发与验收契约

目标：用一个真实业务切片验证 aipipe 从新建仓库、初始化、发布、开发、独立验收到合并的流程。

采用无第三方依赖的 HTML/CSS/JavaScript ES modules；Node 内置测试。禁止 eval/Function 动态执行输入。

## 行为
- 四则运算遵循乘除优先：2+3*4=14；支持负数和小数，0.1+0.2 显示 0.3。
- 按钮与键盘输入一致，Enter/= 求值、Backspace 退格、Escape / Delete 清空。
- 重复小数点被忽略；空输入不崩溃；除零和非法表达式给出明确错误，清空后可继续。
- 求值后数字开始新表达式，运算符接续结果，重复等号保持当前结果。
- 320px 宽度可使用，无横向溢出，按钮可聚焦并有可访问名称。

## 验证
`npm ci`、`npm test`、`npm run build`。业务测试位于 tests/，构建产物 dist/ 不提交。
独立 reviewer 在当前提交的干净检出重跑测试，真实浏览器验证按钮、键盘、错误恢复及窄屏。

## 全流程验收
开发使用 Developer App，验收/合并使用独立 Delivery App。保留真实 ci、SHA 绑定 Review、旧审批失效、新 SHA 重新批准、squash 合并、Issue 关闭和远端分支删除证据。
初始化阶段业务尚未实现时 ci 应真实失败；不能将模板检查作为业务通过证明。
当前宿主子 agent 为独立上下文，但并非操作系统凭据隔离。
